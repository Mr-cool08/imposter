# Namnkollision med matpaketet

Katalogkontrollen matchar Clash Royale-kortet `clash-royale-rocket` med `food-arugula` genom matpostens engelska alias `Rocket`. De är två olika begrepp. Behåll kortets officiella namn och ändra matpostens alias till det etablerade `salad rocket` i matpaketet. Kör sedan om den gemensamma katalogkontrollen.
